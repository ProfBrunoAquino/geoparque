# Exploradores da Quarta Colônia

Aplicativo educativo sobre paleontologia e o Geoparque Quarta Colônia.

## Publicação no GitHub Pages

1. Crie um repositório público chamado `exploradores-quarta-colonia`.
2. Envie todo o conteúdo desta pasta para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment → Source**, selecione **GitHub Actions**.
5. O workflow `.github/workflows/pages.yml` fará a publicação.
6. Após a conclusão, o GitHub mostrará o endereço do aplicativo.

## Instalação como aplicativo

Abra o endereço publicado no Chrome/Edge em um dispositivo compatível. Quando o navegador oferecer a opção, escolha **Instalar aplicativo** ou **Adicionar à tela inicial**.
